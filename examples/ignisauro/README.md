# Ignisauro (*Ignisaurus Rex*)

## Visão Geral
- **Nome Canônico:** Ignisauro
- **Elemento Primário:** Fogo e Magma Vulcânico
- **Descrição:** Dinossauro réptil ígneo de escamas terracota/laranja, ventre creme/amarelado, crista dorsal esmeralda vibrante, garras pálidas e olhos dourados
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Genética Ocular:** Cor primária `#fde047`, pupila `#0f172a`, brilho especular `#ffffff` preservados por todas as fases de vida.
- **Transparência:** Fundo 100% transparente (`#00000000`).
