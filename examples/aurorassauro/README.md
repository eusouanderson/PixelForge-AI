# Aurorassauro (*Aurorasaurus Borealis*)

## Visão Geral
- **Nome Canônico:** Aurorassauro
- **Descrição:** Saurópode majestoso com pescoço longo gracioso, crista de aurora boreal ondulante, cauda estrelar e porte imponente
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Transparência:** Fundo 100% transparente (`#00000000`).
