- **Nome Canônico:** Espectrossauro
- **Elemento Primário:** Éter
- **Descrição:** Dinossauro psíquico primordial envolto em névoa etérea violeta com chifres astrais luminescentes e olhar hipnótico
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Genética Ocular:** Cor primária `#d946ef`, pupila `#4a044e`, brilho especular `#ffffff` preservados por todas as fases de vida.
