# Cristalissauro (*Crystallodraco nobilis*)

## Visão Geral
- **Nome Canônico:** Cristalissauro
- **Elemento Primário:** Cristais e Gemas Prismáticas
- **Descrição:** Anquilossauro blindado com carapaça geométrica azul-safira, placas de quartzo e cauda em maçaneta de diamante que refrata a luz
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Genética Ocular:** Cor primária `#38bdf8`, pupila `#082f49`, brilho especular `#ffffff` preservados por todas as fases de vida.
- **Transparência:** Fundo 100% transparente (`#00000000`).
