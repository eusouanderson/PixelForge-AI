# Terrassauro (*Geosaurus Titan*)

## Visão Geral
- **Nome Canônico:** Terrassauro
- **Elemento Primário:** Terra e Cristal de Esmeralda
- **Descrição:** Colosso tectônico (Pachycephalosaurus + Stegosaurus) com domo craniano polido, placas dorsais pentagonais de esmeralda, punhos de golem e cauda thagomizer
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Genética Ocular:** Cor primária `#f59e0b`, pupila `#1c1917`, brilho especular `#ffffff` preservados por todas as fases de vida.
- **Transparência:** Fundo 100% transparente (`#00000000`).
