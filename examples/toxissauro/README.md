- **Elemento Primário:** Veneno
- **Descrição:** Titã réptil das savanas pantanosas com pústulas ácidas bioluminescentes e presas inoculadoras de veneno
- **Resolução:** 32×32 pixels lógicos
- **Orientação:** Estritamente frontal com visão binocular (ambos os olhos visíveis)
- **Genética Ocular:** Cor primária `#84cc16`, pupila `#14532d`, brilho especular `#ffffff` preservados por todas as fases de vida.
